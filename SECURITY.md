# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

DOMPulse runs locally inside the user's browser with zero cloud telemetry. However, if you discover any security vulnerability (e.g. extension privilege escalation, malicious script injection, or sandbox escape), please report it responsibly:

* **Email:** Open a private security advisory on GitHub or contact the maintainers.
* Please do not report security vulnerabilities through public GitHub issues.
* Maintainers will respond within 48 hours to validate and resolve the issue.
